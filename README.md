# Linha do Tempo MCU

App estático para ver a linha do tempo do Universo Cinematográfico Marvel e marcar o que já assistiu.

- Ordem cronológica (história) ou de lançamento
- Filtros por status, tipo, fase e busca
- Progresso salvo no navegador (localStorage)

Abra `index.html` no navegador ou publique no GitHub Pages. Para adicionar títulos, edite `data.js`.
